# Приклад: пресконференція NASA, 1959

Справжній запис живих людей у залі: шум плівки, луна приміщення, кілька голосів.

| Файл | Що це |
|---|---|
| [`mercury7-1959.flac`](mercury7-1959.flac) | оригінал: 60.5 с, моно, 48 кГц |
| [`mercury7-1959.cleaned.flac`](mercury7-1959.cleaned.flac) | результат `voice-normal process` |
| [`mercury7-1959.report.md`](mercury7-1959.report.md) | звіт перевірки цього прогону |

Говорять троє:

1. Роберт Гілрут, керівник Project Mercury, дякує залу.
2. Т. Кіт Гленнан, адміністратор NASA, оголошує наступного доповідача.
3. Доктор Рендольф Лавлейс розповідає про медичний відбір астронавтів.

## Результат

Усі 8 гейтів пройдено з першого раунду:

| Що | Оригінал | Результат |
|---|---|---|
| DNSMOS OVRL / BAK / SIG | 2.61 / 2.82 / 3.55 | 3.40 / 4.15 / 3.64 |
| Розбіжність розшифровок Whisper | — | 3.4%, жодне слово не замінене |
| Схожість голосу (ECAPA) | — | 0.80 (найменша у вікні 10 с — 0.75) |
| Зсув | — | −0.02 мс, по вікнах до 0.8 мс |
| Гучність | — | −16.0 LUFS, true peak −1.5 dBTP |

Обробка зайняла 1:41 на Intel i5-1135G7 без GPU, з них перевірка — 0:34.

Лімітер тут працював частіше, ніж на тестових записах: 2.08% часу, до 6.6 дБ. Причина
в тому, що відновлений голос має різкі піки на приголосних. Гейти це пропускають, бо
true peak і гучність у межах. Але це вже не «лише окремі піки», тож під час
прослуховування варто звернути на це увагу.

Відтворити:

```powershell
.\voice-normal process docs\samples\mercury7-1959.flac --out cleaned\
```

## Джерело й ліцензія

- **Запис:** «Mercury 7 introductory press conference (part 1)», NASA, 9 квітня 1959,
  котушка 491-AAF.
- **Де взято:** [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Mercury_7_introductory_press_conference_(part_1)_-_491-AAF.ogg).
  Першоджерело — [Internet Archive](https://archive.org/details/FirstSevenAstronautsPressConference).
  SHA-1 завантаженого файлу: `e84f549b7cb6effe9d0880779901113f19ef4bca`.
- **Ліцензія:** суспільне надбання (public domain) у США. Запис повністю створено NASA,
  а роботи федерального уряду США не охороняються авторським правом. NASA не
  схвалює і не рекламує цей проєкт.
- **Що змінено:** вирізано фрагмент 4:26–5:26.5 (`ffmpeg -ss 266.0 -t 60.5`), зведено
  в моно, 48 кГц, 16 біт. Оригінал Ogg Vorbis у репозиторій не входить.
- **Результат:** `process` пише WAV 24 біти; тут він збережений як FLAC 16 біт, щоб
  репозиторій лишався легким.
